# Сборка ZBS VPN 0.2.3.38-background (67)

Этот репозиторий содержит соответствующие исходники приложения и модификаций ядра текущей beta. Байты исходных файлов приложения, ядра и конфигурации сборки сохранены. Инструкции сборки также представлены в [`docs/android-build-reference.yml`](docs/android-build-reference.yml).

Инструменты проверенной CI-сборки:
- Linux, JDK 17, Gradle 8.11.1.
- Go 1.26.8, `GOTOOLCHAIN=local`.
- Android SDK platform 35, build-tools 35.0.0, NDK 27.2.12479018.
- sing-box/libbox 1.13.12 и AmneziaWG Go v3.1.20260828; публичные источники и версии описаны в core/build.sh и Go/Gradle-файлах.

Установите эти инструменты, задайте ANDROID_HOME и ANDROID_NDK_HOME. Из корня исходников выполните:

```sh
bash core/build.sh
gradle --no-daemon :app:testDebugUnitTest :app:assembleDebug
```

Для исходников сторонних зависимостей используются публичные ссылки и закреплённые версии в сценариях сборки и файлах Gradle/Go. Сохранены оригинальные лицензии и copyright-уведомления. Сборка требует доступа к этим источникам и реестрам зависимостей.

Приватного ключа подписи и пользовательских профилей в репозитории нет. Без собственной постоянной подписи Gradle создаёт локальную debug-подпись. Такая сборка не предназначена для обновления официального APK поверх установленного приложения: ключ разработчика не распространяется. Проверенный распространяемый APK подписан постоянным ключом.

CI-рецепт сохранён как справочный файл: публикация исходников не запускает сборки и не расходует минуты GitHub Actions.
