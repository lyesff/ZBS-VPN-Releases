# ZBS VPN
**Zero Barriers System**

Android VPN на WARP и AmneziaWG с маскировкой I1 и необязательным DNS over HTTPS для отдельных сервисов с региональными ограничениями.

## Скачать
[Первая beta — APK и файлы выпуска](https://github.com/lyesff/ZBS-VPN-Releases/releases/tag/v0.2.3.32-beta.1)

Нужны **Android 10+** и устройство **ARM64 / arm64-v8a**. Скачайте файл с расширением **.apk** из раздела Assets. Архив **source.zip** предназначен для исходников и не устанавливается на телефон.

## Начало работы
1. Установите APK и откройте ZBS VPN.
2. Создайте профиль или импортируйте свой AmneziaWG `.conf`.
3. Нажмите «Подключить с маскировкой» и подтвердите системное разрешение VPN.
4. При необходимости выберите DNS в «Обход геоблокировок» при отключённом VPN, затем подключитесь заново.

Для DNS приложения в Chrome используйте DNS системы / текущего поставщика. Собственный DNS браузера и Android «Частный DNS» могут переопределить этот выбор.

## Возможности
- Подключение одной кнопкой и проверка HTTPS.
- WARP через AmneziaWG с маскировкой I1.
- Выбор DoH-провайдера или своего HTTPS-адреса.
- Внешний IP, время подключения и скорости.
- Восстановление при смене Wi-Fi и мобильной сети.

## Ограничения beta
Поддерживается IPv4; IPv6 блокируется. При смене сети соединения могут прерываться. Работа на всех операторах и гостевых Wi-Fi не гарантируется. WARP не является гарантированным выбором страны, а доступность сервисов через Smart DNS зависит от провайдера.

При возвращении Wi-Fi выполняется служебная HTTPS-проверка этой сети вне VPN. Имя DoH-сервера разрешается до запуска туннеля. Для блокировки трафика вне VPN используйте системные Always-on и «Блокировать соединения без VPN», отдельно проверив их на устройстве.

## Проверка файлов
В Assets приложен `SHA256SUMS`. Он содержит SHA-256 APK и архива исходников. На Windows: `Get-FileHash .\ZBS-VPN-0.2.3.32-beta.1-arm64-v8a.apk -Algorithm SHA256`.
